# SeriCloud

O SeriCloud é um projeto fictício de uma plataforma de aluguel de boardgames criado para praticar conhecimentos em HTML, CSS e JavaScript.

## Sobre o projeto

O sistema simula uma plataforma simples de aluguel de jogos de tabuleiro, permitindo visualizar jogos disponíveis e alterar seu status entre alugado e disponível.

Este projeto foi desenvolvido apenas para fins de estudo e prática de desenvolvimento front-end.

## Funcionalidades

- Exibição de jogos
- Sistema de aluguel e devolução
- Interface responsiva
- Alteração dinâmica de elementos com JavaScript
- Layout estilizado com CSS

## Jogos disponíveis

- Monopoly
- Ticket to Ride
- Takenoko

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
