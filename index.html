Bem-vindos ao SeriCloud

O SeriCloud é uma plataforma de aluguel de boardgames criada para tornar o acesso aos melhores jogos de tabuleiro mais simples, rápido e acessível. Aqui você pode visualizar os jogos disponíveis, conferir o status de aluguel e reservar seus títulos favoritos de maneira prática.

Como funciona

  • 1. Escolha um jogo disponível na plataforma.
  • 2. Clique no botão “Alugar” para reservar o jogo.
  • 3. O status do jogo será alterado automaticamente para “Devolver”, indicando que ele já está alugado.
  • 4. Após utilizar o jogo, clique em “Devolver” para liberá-lo novamente para outros usuários.

    • Jogos disponíveis

    Monopoly

    • Ticket to Ride

    • Takenoko

  • Um jogo leve e divertido onde os jogadores cuidam de um jardim japonês e alimentam um panda gigante.

Regras da plataforma

  • Após terminar a utilização, o jogo deve ser devolvido pelo sistema.
  • Jogos alugados permanecem indisponíveis até serem devolvidos.

Objetivo do SeriCloud

O SeriCloud é apenas uma criação ficticia para fins de estudo e aplicação de conhecimento em HTML, CSS e JavaScript.
